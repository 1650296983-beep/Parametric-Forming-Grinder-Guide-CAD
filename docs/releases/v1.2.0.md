# v1.2.0 工作台更新

- 重整参数输入、计算复核和生成结果布局，加入真实 DXF 画布、截面/侧视切换、缩放与图层显隐。
- 生成阶段与后端真实进度同步，支持断线恢复，完善正式图纸校验和任务状态提示。
- 新增浅色/深色/跟随系统主题、命令面板和快捷键、草稿恢复、规格粘贴规范化与实时解析提示。
- 优化历史任务、确认弹窗、操作通知、字体和按钮反馈；补回 Windows 字体回退并升级 Vite 至 6.4.4。

本版继承 v1.1.8 的七机型砂轮投影修复，以及按槽宽 30% 并受各机台原上限限制的入丝口规则，未变更制造几何公式。

发布顺序经用户明确确认：先推送源码供 Windows 签名构建使用，GitHub Release 保持草稿；下载并验证同一组产物，从本地发布 COS 并独立核验成功后，再公开 GitHub Release。沿用现有不可变版本目录、签名校验及 stable 最后晋级规则。
